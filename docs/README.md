## Viewing upcoming deadlines

Use `remind` to view incomplete deadlines that are due from now through the next seven days. The
reminder list is ordered by due time. It does not include todo tasks, events, completed deadlines,
or overdue deadlines.

Example: `remind`

```
Here are your upcoming deadlines:
[D][ ] submit report (by: Dec 2 2019 1800)
```

If no deadline is due in that period, Chausistant displays:

```
Here are your upcoming deadlines:
No upcoming deadlines in the next 7 days.
```
